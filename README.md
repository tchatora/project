## File Names, Project Organization and Virtual Environments

Practical application for file Naming, Project Organization, Virtual Environments using Github version control.

**File names** are part of organization, efficiency of projects and ease collaboration by ensuring `Machine Readability`, `Human Readability`, and `Compatibiliy with Default Ordering/Sorting`.

**Project Organization** keeps the project clean and easy to follow. There are notable differences in file organizationb between projects for `Data Analysis` and `Data Science Tools`.

**Virtual Enviroments** ensure repeatability of computations environments.
